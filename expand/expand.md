3. A compiled language translate the source code into machine language in bulk, whereas an interpreted language converts the source code into machine language line by line during run time. Js began as an interpreted language, but modern Js is now considered a Just-In-Time Compiled language which is a hybrid of the two types. Js being a JIT Compiled language allows it to run code while skipping a build step. This means one can just refresh a page to see Js in action. Js can also runs cross-browser. However, JS suffers a performance hit as optimization and compilation occurs during runtime.
